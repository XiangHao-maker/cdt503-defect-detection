# CDT503 · 工业视觉质检

一个能在手机与电脑浏览器中运行的工业外观异常检测演示。模型通过 ONNX Runtime Web 在浏览器本地推理，上传的照片不会发送到服务器。

## 使用

打开 GitHub Pages 地址，选择瓶子、瓷砖或金属螺母，再选择测试样例或本机图片，点击“开始检测”。首次使用需要下载模型，之后同一模型会在当前页面缓存。

- 主模型：PatchCore-lite，512 个代表特征。
- 对照：128 特征库和卷积自编码器。
- 输出：异常分数、正常/异常判断和缺陷热力图。
- 模型适用范围只覆盖所选的三类 MVTec AD 产品外观，不能识别任意产品。

## 测试结果

| 类别 | 主模型图像 AUROC | 漏检 | 误报 |
| --- | ---: | ---: | ---: |
| bottle | 0.9984 | 0 | 2 |
| tile | 0.9978 | 0 | 1 |
| metal_nut | 0.9829 | 3 | 3 |

以上是固定划分、单随机种子下 Python 原模型的独立测试结果，AUROC 不是准确率。浏览器模型由相同权重转换，转换后在 30 个样例上与 Python 结果比对，最大分数绝对误差约 0.0000021。浏览器实际表现还取决于图片解码、设备和运行环境。

## 本地预览

```sh
python -m http.server 8000
```

打开 `http://localhost:8000`。不能直接双击 `index.html`，因为浏览器需要通过 HTTP 加载模型和 WebAssembly。

## 部署

这是完整静态网站，根目录含 `.nojekyll`，可直接通过 GitHub Pages 从 main 分支根目录发布。无需 Python 服务、云 API 或收费推理后端。
